01 / About

Still learning.
Always building.

This is my corner of the internet — a place to share the work, experiments, lessons, and ideas behind my developer journey.

01+

A journey built project by project.

I believe the fastest way to improve is to create something, test it, learn from the rough edges, and keep going.

Technology should turn ideas into something useful.

I’m interested in the full process of creating digital products: understanding a problem, shaping an interface, writing the code, connecting services, testing the experience, and improving it over time.

My current learning path includes JavaScript, React Native, Expo, and Supabase. I also enjoy building websites, exploring UI concepts, and documenting what I learn.

This portfolio is designed to grow with me. As projects become more complete, I’ll update their descriptions, demos, screenshots, and lessons learned rather than pretending every experiment is already a finished product.

04 / Coding journey

Progress is a practice,
not a finish line.

A simple timeline of the way I approach learning: explore, build, test, and refine.

Phase 01 · Foundations

Learning the building blocks

Practice programming fundamentals, understand how websites work, and get comfortable reading and editing code.

Phase 02 · First prototypes

Turning ideas into interfaces

Build early app and website prototypes to learn about layouts, navigation, state, and user flows.

Phase 03 · Connected products

Exploring backend features

Experiment with authentication, databases, and app data using tools such as Supabase.

Phase 04 · What comes next

Improve quality and ship thoughtfully

Focus on reliability, accessibility, clearer documentation, better testing, and honest project status updates.
